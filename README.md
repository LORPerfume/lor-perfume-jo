# OrderFlow Fresh Accounting

نسخة جديدة من الصفر، بدون أي بيانات تجريبية وبدون seeders.

## الفكرة
- إنشاء الأوردر يبدأ تلقائياً: الحالة `جديد` وطريقة الدفع `غير مدفوع`.
- صفحة الأوردرات اليومية هي مركز التحكم.
- عند تحويل الحالة إلى `تم تسليمه لشركة التوصيل` أو `تم التسليم للعميل`: يتم إخراج الكمية من المخزون تلقائياً.
- عند تحويل الحالة إلى `راجع/ملغي/مرفوض`: يتم إرجاع الكمية للمخزون إذا كانت خرجت سابقاً.
- عند تغيير طريقة الدفع إلى `ذمم شركة التوصيل`: يظهر المبلغ مباشرة في كشف ذمم شركة التوصيل، بشرط اختيار شركة توصيل.
- عند تغيير طريقة الدفع إلى `نقدي/كليك/بنك/بطاقة/محفظة`: يتم إنشاء دفعة تلقائية وصندوق تلقائي وحركة قبض.
- عند تغيير طريقة الدفع إلى `غير مدفوع`: يظهر المبلغ في ذمم العملاء.

## ملاحظات مهمة
- لا يوجد أي منتج جاهز.
- لا يوجد أي أوردر جاهز.
- لا يوجد أي صندوق جاهز.
- لا يوجد أي حركة مخزون أو حركة مالية جاهزة.
- لإنشاء مستخدم بعد النشر على Render:

```bash
python manage.py createsuperuser
```

## Render
Build command:

```bash
./build.sh
```

Start command:

```bash
gunicorn orderflow.wsgi:application
```

ضع Environment Variables عند الحاجة:
- SECRET_KEY
- DATABASE_URL
- ALLOWED_HOSTS
- CSRF_TRUSTED_ORIGINS مثل: https://your-app.onrender.com
