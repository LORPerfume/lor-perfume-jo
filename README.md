# Warehouse Receivables - نظام مستودعات وذمم

نسخة جديدة جاهزة للنشر، بدون أي داتا تجريبية: لا عملاء، لا منتجات، لا أوردرات، لا دفعات، ولا حركات مخزون جاهزة.

## ماذا يحتوي النظام؟

- صفحة رئيسية فيها زر واضح: طلب جديد.
- شاشة طلب جديد تجمع بيانات المشتري + المنتج + حالة الطلب + طريقة الدفع/الذمة.
- طريقة الدفع تشمل: نقدي، كليك، تحويل بنكي، بطاقة، محفظة، وذمم شركة التوصيل.
- صناديق متابعة لكل طريقة دفع، وتُنشأ تلقائياً عند أول دفعة أو من خلال أمر اختياري لإنشاء صناديق فارغة.
- مستودع: منتجات، كميات، إدخال، إخراج، مرتجع، تالف، تسوية جرد.
- كشوفات ذمم وأرصدة متبقية حسب الطلبات وطرق الدفع.
- تقارير مستودع، أوردرات، ذمم، قبض، مبيعات، مرتجعات.
- تصدير Excel بصيغة XLSX للأوردرات والمخزون وكشف الذمم.

## مهم جداً

لا يوجد ملف seed أو demo، ولا يوجد أي كود يضيف بيانات تجريبية تلقائياً.
الصناديق الفارغة تعتبر إعدادات تشغيل فقط وليست بيانات تجريبية.

## التشغيل محلياً

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

اختيارياً، لإنشاء صناديق فارغة لطرق الدفع:

```bash
python manage.py init_cashboxes
```

## النشر على Render

الملف جاهز للنشر كما هو. Build command:

```bash
./build.sh
```

Start command:

```bash
gunicorn order_system.wsgi:application
```
