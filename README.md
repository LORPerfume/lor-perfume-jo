# OrderFlow - نسخة فاضية 100%

هذه النسخة مخصصة للبداية من الصفر بدون أي بيانات تجريبية.

المهم:
- لا يوجد منتجات جاهزة.
- لا يوجد طلبات جاهزة.
- لا يوجد عملاء جاهزين.
- لا يوجد صناديق جاهزة.
- لا يوجد حركات صندوق.
- لا يوجد حركات مستودع.
- لا يوجد مرتجعات.
- لا يوجد شركات توصيل جاهزة.
- لا يوجد Seeders أو Fixtures أو Demo Data.

## مهم جدًا عند الرفع على Render
إذا كان عندك Database قديمة من النسخ السابقة، هذه النسخة تحتوي Migration اسمها:

`0007_wipe_all_business_data_empty_start`

وظيفتها حذف كل بيانات النظام التشغيلية السابقة عند أول Deploy لهذه النسخة، مع الإبقاء على حسابات المستخدمين/الأدمن.

بعد الرفع، يجب أن تظهر كل الصفحات فاضية، وأي جدول يجب أن يعرض "لا يوجد بيانات" أو أرقام صفر.

## التحقق بعد النشر
من Shell أو Console يمكن تشغيل:

```bash
python manage.py verify_empty_start
```

إذا رجع:

`OK: business database is empty.`

فالنظام فاضي فعليًا.
