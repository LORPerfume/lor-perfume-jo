# OrderFlow - نسخة متابعة الأوردرات والمخزون والصناديق

هذه نسخة كاملة بديلة ومختصرة لإدارة:

- الأوردرات اليومية والمتابعة.
- تحويل حالة الأوردر إلى: جديد، قيد التجهيز، مع التوصيل، تم التسليم، مرتجع، ملغي، وغيرها.
- تسجيل الدفع حسب الطريقة: كليك، تحويل بنكي، نقدي، بطاقة، شركة التوصيل، محفظة إلكترونية.
- إنشاء صندوق تلقائي لكل طريقة دفع عند تسجيل أول دفعة.
- متابعة شركة التوصيل وكشف التحصيل.
- حركات المخزون: إدخال، إخراج/تسليم، مرتجع، تسوية، تالف.
- تقارير حسب الفترة: مبيعات، قبض، ذمم، ربح، مصاريف، إدخال مخزون، إخراج مخزون، مرتجعات.

## مهم جداً

تم حذف ملف البيانات التجريبية `seed_demo.py` من هذه النسخة، ولا يوجد كود يضيف داتا تجريبية تلقائياً.

## إنشاء الصناديق بدون بيانات تجريبية

يمكنك تشغيل الأمر التالي لإنشاء صناديق فارغة لكل طرق الدفع فقط:

```bash
python manage.py init_cashboxes
```

أو اترك النظام ينشئ صندوق طريقة الدفع تلقائياً عند تسجيل أول دفعة.

## التشغيل محلياً

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py init_cashboxes
python manage.py runserver
```

## ملاحظة عمل النظام

- عند تسجيل دفعة واختيار طريقة الدفع، يتم ربطها بصندوق نفس طريقة الدفع تلقائياً إذا لم تختَر صندوقاً يدوياً.
- عند تحويل حالة الأوردر إلى `تم التسليم` يتم تسجيل حركة إخراج مخزون تلقائياً للأوردر.
- عند تسجيل مرتجع يتم تحويل حالة الأوردر إلى `مرتجع`، وإذا اخترت إرجاعه للمستودع يتم تسجيل حركة مرتجع في المخزون.
