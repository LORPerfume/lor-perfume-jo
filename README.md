# LOR Order & Warehouse System

نظام بسيط لإدارة طلبات شركة LOR، المخزون، ذمم شركات التوصيل، المرتجعات، والتقارير.

## التشغيل المحلي

```bash
pip install -r requirements.txt
python app.py
```

افتح: http://127.0.0.1:5000

## الرفع على GitHub وRender

1. احذف ملفات المشروع القديم من مستودع GitHub.
2. ارفع ملفات هذا المشروع كاملة كما هي.
3. على Render اختر Web Service.
4. Build Command:
   ```bash
   pip install -r requirements.txt
   ```
5. Start Command:
   ```bash
   gunicorn app:app
   ```

## ملاحظة مهمة عن قاعدة البيانات على Render
النظام يستخدم SQLite داخل مجلد `instance/app.db` بدون بيانات تجريبية. على Render المجاني قد تُفقد قاعدة البيانات عند إعادة التشغيل إذا لم تضف Persistent Disk. الأفضل إضافة Disk وربطه بمجلد `/opt/render/project/src/instance` أو استخدام قاعدة PostgreSQL لاحقًا.

## الشاشات
- الرئيسية: ملخص اليوم والذمم والمخزون.
- إضافة طلب: اسم العميل، الطلب، السعر، الحالة، طريقة الدفع، شركة التوصيل.
- طلبات اليوم: تغيير الحالة بنهاية اليوم.
- شركات التوصيل: ذمم كل شركة وعدد الطلبات والمبالغ المستحقة.
- المخزون: إضافة منتجات، إدخال/إخراج، متابعة المتوفر.
- المرتجعات: الطلبات المرتجعة وتأثيرها.
- التقارير: حسب الفترة، مبيعات، إدخال، إخراج، ربح، مرتجع.
